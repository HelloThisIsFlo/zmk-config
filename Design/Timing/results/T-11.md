## 🔍 Mechanism notes (observed, cross-checked with source)

- **Ladder does not drift.** Each rung executes at exactly `deadline + 1` even after re-arming (pos 4: deadlines t+11/t+16/t+18 → executed t+12/t+17/t+19). Reason: `combo.c:417` re-arms with `K_MSEC(first_timeout - k_uptime_get())`, i.e. relative to the absolute deadline, so the previous rung's +1 is absorbed. `filter_timed_out_candidates(timeout_task_timeout_at)` (`combo.c:473`) prints the deadline as `timestamp=`, hence `timestamp=` = intended, prefix = execution.
- **AK layer timeline after a solo `&ak`**: HID↓ at D, HID↑ + `layer N state 1` at D+11, `layer N state 0` at D+112 (e.g. pos 0: D = +17 → ON +28, OFF +129), same as RIG.md T-01-r2.
